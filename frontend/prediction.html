How this works

InsightBoard aggregates sales by month, then fits a simple linear regression line (y = slope × month + intercept) over that trend. The line's value one step beyond the last known month becomes the prediction. This intentionally avoids heavier machine learning — the same interface is designed to plug into a real Python/scikit-learn service later without changing the UI.
